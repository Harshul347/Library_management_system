# Library Management System

## 📌 About the Project
The Library Management System is a C++ project designed to manage basic library operations, including book records and book issue and return activities.

## ✨ Features
- Add new books
- Display all available books
- Search for a book
- Issue books to students
- Return issued books
- Manage book records

## 🛠️ Technologies Used
- C++
- Data Structures
- Object-Oriented Programming (OOP)

## 📚 Concepts Used
- Classes and Objects
- Arrays or Vectors
- Functions
- Loops and Conditional Statements
- Searching Algorithms

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Compile the C++ source file using a C++ compiler.
4. Run the executable file.

### Compile and Run
```bash
g++ main.cpp -o library
./library
```

On Windows, run the compiled program using:
```bash
library.exe
```
